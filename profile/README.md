# Equinix

Official open-source SDKs, Terraform providers and modules, and Pulumi packages for the [Equinix](https://www.equinix.com) platform (Fabric, Network Edge, Metal and more).

📚 API documentation: <https://docs.equinix.com/equinix-api/>

## SDKs

Client libraries generated from the Equinix API specifications.

| Language | Repository | Latest release | Install |
|---|---|---|---|
| Go | [equinix-sdk-go](https://github.com/equinix/equinix-sdk-go) | [![release](https://img.shields.io/github/v/release/equinix/equinix-sdk-go)](https://github.com/equinix/equinix-sdk-go/releases) | `go get github.com/equinix/equinix-sdk-go` ([pkg.go.dev](https://pkg.go.dev/github.com/equinix/equinix-sdk-go)) |
| Python | [equinix-sdk-python](https://github.com/equinix/equinix-sdk-python) | [![release](https://img.shields.io/github/v/release/equinix/equinix-sdk-python)](https://github.com/equinix/equinix-sdk-python/releases) | `pip install equinix` ([PyPI](https://pypi.org/project/equinix)) |
| Java | [equinix-sdk-java](https://github.com/equinix/equinix-sdk-java) | [![release](https://img.shields.io/github/v/release/equinix/equinix-sdk-java)](https://github.com/equinix/equinix-sdk-java/releases) | Maven: `com.equinix:equinix-sdk-java` |
