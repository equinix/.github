# Equinix

Official open-source SDKs, Terraform providers and modules, and Pulumi packages for the [Equinix](https://www.equinix.com) platform (Fabric, Network Edge, Metal and more).

📚 API documentation: <https://docs.equinix.com/equinix-api/>

## SDKs

Client libraries generated from the Equinix API specifications.
